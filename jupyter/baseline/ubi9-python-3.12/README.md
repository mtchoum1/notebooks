# jupyter/baseline/ubi9-python-3.12

Baseline Jupyter workbench image with Python 3.12 on UBI 9.

## Status

- Resolves RPMs online during the image build (`hermetic: false`).
- Prefetches Python packages as **PyPI sdists** with [Hermeto](https://github.com/hermetoproject/hermeto).
  `uv` is the exception: Hermeto fetches its wheels because the published
  sdist's `Cargo.lock` does not match `Cargo.toml`.
- Installs those artifacts offline via
  `uv pip install --no-index --no-binary :all: --only-binary uv --find-links /cachi2/output/deps/pip`.
- Keeps JupyterLab feature set (Elyra, Kale, PDF export) with a lean Python footprint.
- Does not use a component `prefetch-input/` tree; RPM hermetic conversion stays deferred.

## Local build

```bash
uv sync --locked

RELEASE_PYTHON_VERSION=3.12 BUILD_ARCH=linux/amd64 \
  ./scripts/lockfile-generators/prefetch-all.sh \
    --component-dir jupyter/baseline/ubi9-python-3.12 --flavor cpu

make jupyter-baseline-ubi9-python-3.12 BUILD_ARCH=linux/amd64 PUSH_IMAGES=no
```

`make` mounts `cachi2/output` into the build when `cachi2/output/deps/pip` exists. It does **not** overlay `/etc/yum.repos.d/`, so `dnf` still uses the base image's online repos.

The image `FROM`s a RHEL Python base, so local builds need Red Hat entitlement certs (see [docs/subscribed-builds.md](../../../docs/subscribed-builds.md)). Without them, `subscription-manager release` fails during `cpu-base`.

For ODH local builds, `build-args/cpu.conf` supplies the baseline ODH settings.
The downstream RHOAI variant continues to use `build-args/konflux.cpu.conf`.

## Python lockfile flow

Public-index lock layout (no `uv.lock.d/` directory):

- `pyproject.toml` is the source of truth
- `pylock.toml` is generated in place at the image root
- `requirements.cpu.txt` is generated from that `pylock.toml` with **sdist hashes** (`--sdist-hashes prefer`) so Hermeto source-only prefetch can match artifacts
- `requirements-build.cpu.txt` is generated by `pybuild-deps` (PEP 517 build deps for compiling sdists)
- Dockerfiles install with `uv pip install --no-index --no-binary :all: --only-binary uv --find-links /cachi2/output/deps/pip`

Regenerate after Python dependency changes:

```bash
./scripts/lockfile-generators/create-requirements-lockfile.sh \
  --pyproject-toml jupyter/baseline/ubi9-python-3.12/pyproject.toml \
  --flavor cpu
```

Then prefetch sdists:

```bash
./scripts/lockfile-generators/helpers/hermeto-fetch-pip.sh \
  --component-dir jupyter/baseline/ubi9-python-3.12 --flavor cpu
```

## CI and Konflux

- ODH PR PipelineRun: `.tekton/odh-workbench-jupyter-baseline-cpu-py312-c9s-pull-request.yaml`
- Manual PR trigger: `/build-jupyter-baseline`
- Konflux prefetches pip sdists (`type: pip`) with `binary.packages: uv` only,
  and keeps `hermetic: false` so RPM `dnf` can use the network
